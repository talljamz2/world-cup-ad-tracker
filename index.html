How we score

The Composite Score is a single 0–100 number that summarizes how a spot is performing on the dimensions marketers actually care about. Each factor is normalized against the leader in the dataset, then combined using the weights below. When sentiment can't be confidently measured (sample size below 20 valid comments), the remaining weights are renormalized so a thinly-commented spot isn't punished.

Reach
40%
YouTube views — how many eyeballs the spot has earned.
Resonance
20%
Engagement rate — likes plus comments per view. Quality controlled for paid amplification.
Sentiment
25%
Like-weighted sentiment of the top 100 comments. The audience-endorsed reaction, not the average commenter.
Velocity
15%
Views per day since release. Trajectory check — rewards spots that are actively climbing.

Source: YouTube Data API v3, refreshed hourly. Sentiment scored with VADER (compound, -1 to +1), like-weighted with 1 + ln(1 + likes), normalized to 0–100. Channel-staff comments, URLs, and obvious bot patterns are filtered before scoring.
